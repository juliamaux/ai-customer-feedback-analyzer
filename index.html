AI Customer Feedback Analyzer

Personal learning project by Júlia Vilela · Customer Success & AI

The problem

Customer Success teams receive large amounts of qualitative feedback that can be difficult to organize manually. This project explores how AI can turn unstructured feedback into actionable insights.

Workflow

Customer feedback → AI analysis → Customer risk → Recommended action → Suggested response

Example

Feedback: “I like the platform, but the onboarding was confusing and I couldn't figure out how to set up my first workflow.”

  • Sentiment: Neutral / Negative
  • Topic: Onboarding
  • Customer risk: Medium
  • Main issue: Difficulty setting up the first workflow
  • Recommended action: Offer guided onboarding assistance

Suggested response: Acknowledge the difficulty, clarify the setup steps, and offer a short onboarding session.

AI prompt

You are a Customer Success analyst. Analyze the customer feedback below and return:
1. Sentiment
2. Topic
3. Customer risk (Low, Medium, High)
4. Main issue
5. Recommended next action
6. A concise, empathetic customer response

Do not invent facts. Base the analysis only on the feedback provided.

What I learned

This project helped me practice prompt design, AI-assisted analysis, customer feedback interpretation, risk identification, and converting qualitative information into practical next steps. I also learned that AI output still needs human review and context before being used with customers.

Project scope

This is a personal learning project using fictional/example customer feedback. No confidential customer information is used.
